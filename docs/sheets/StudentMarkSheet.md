# Excel Sheet: StudentMarkSheet

> Add this sheet to the Excel workbook and register it in the kutties-api
> so the sync endpoint `GET /api/StudentMarkSheet` is available.

---

## Sheet Name

```
StudentMarkSheet
```

---

## Columns (in order)

| # | Column Header  | Type    | Required | Notes                                                    |
|---|----------------|---------|----------|----------------------------------------------------------|
| 1 | `id`           | Text    | ✅        | UUID — auto-generated by the app on create               |
| 2 | `Student`      | Text    | ✅        | Student registration number (FK → students.RegNumber)    |
| 3 | `ExamName`     | Text    | ✅        | e.g. "Term 1", "Mid Term", "Final Exam"                  |
| 4 | `ExamDate`     | Date    | ✅        | Date the exam was held (dd/MMM/yyyy)                     |
| 5 | `Subject`      | Text    | ✅        | Subject name, e.g. "Mathematics", "English"              |
| 6 | `SubjTeacher`  | Text    |          | Teacher who teaches this subject (email or name)         |
| 7 | `MaxMarks`     | Number  | ✅        | Maximum marks for this subject/exam                      |
| 8 | `MarksObtained`| Number  | ✅        | Marks scored by the student                              |
| 9 | `Grade`        | Text    |          | A+ / A / B / C / D / F — auto-computed if left blank     |
|10 | `Remarks`      | Text    |          | Teacher remarks for this entry                           |
|11 | `RecordedBy`   | Text    |          | Teacher who entered/recorded this mark                   |
|12 | `Revision`     | Number  |          | Version counter — incremented on each update             |
|13 | `Lastmodified` | Text    |          | ISO 8601 timestamp — set by the app on every write       |

---

## Grade auto-computation rule

When `Grade` is blank, the app computes it from `(MarksObtained / MaxMarks) × 100`:

| Percentage | Grade |
|-----------|-------|
| ≥ 90      | A+    |
| ≥ 75      | A     |
| ≥ 60      | B     |
| ≥ 45      | C     |
| ≥ 35      | D     |
| < 35      | F     |

---

## API endpoints required (kutties-api)

| Method   | URL                              | Description                    |
|----------|----------------------------------|--------------------------------|
| `GET`    | `/api/StudentMarkSheet`          | List all rows (supports `?sinceDate=YYYY-MM-DD`) |
| `POST`   | `/api/StudentMarkSheet`          | Create a new row               |
| `PUT`    | `/api/StudentMarkSheet/:id`      | Update an existing row         |
| `DELETE` | `/api/StudentMarkSheet/:id`      | Delete a row                   |
